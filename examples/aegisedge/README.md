# AegisEdge — hand-directed launch film

A ~62-second film for [AegisEdge](https://github.com/akshatinnovate-png/AegisEdge),
an offline-first edge memory and intelligence platform built for Code Cubicle 6.0
(Problem Statement 03).

```bash
python3 examples/aegisedge/direct.py --quality good --gif
```

## Why this one is hand-directed

Every other example in this repo was generated by pointing cased2.0 at a
repository. This one could not be: the source material was a **pitch document**,
not a codebase, so there was no import graph to read and no source to show.

That is exactly what `cased-slim` is for. `direct.py` writes the shot list by
hand and hands it to the same engine — the scorer still sets the tempo, and
`_lay_out` still snaps every cut to the beat grid. It is the worked example of
the slim workflow.

## The edit

The structure comes from the document's own thesis — three pillars, each
immediately cashed out with the measurement that backs it. Claim, then proof.

| | |
|---|---|
| **It survives** | 0 writes lost after SIGKILL; 60 acknowledged, 60 recovered |
| **It decides** | 7 of 7 deletions delivered on a dying link, against 0 of 7 |
| **It proves** | 0 invariant failures in 1.73M operations; the control breaks 435 of 500 |

The midpoint is the line the document itself nominates:

> Most teams will tell you their system works. We hand you the crowbar.

Then the architecture (four planes, everything leaning on storage), the life of
one memory as a pipeline, the on-device stack, and the results.

## On the numbers

**Every figure and every quoted sentence is taken verbatim from the author's
pitch document.** Nothing was rounded up, dramatised or invented — which matters
more than usual for a film whose whole argument is falsifiability.

## Theme

Black and orange, as requested: a near-black `#07060A` ground so the orange
`#FF6B1A` reads as heat rather than decoration, over a starfield — the project
is about nodes surviving alone in the dark.

## Files

| File | What it is |
|---|---|
| `direct.py` | the hand-written shot list and the render command |
| `aegisedge.mp4` | the film |
| `aegisedge.gif` | looping, for a README |
| `poster.png` | midpoint frame, doubles as an OG image |
| `spec.json` | the full edit, re-renderable as-is |

The soundtrack regenerates from the seed in `spec.json`:

```bash
python3 -m cased.score 62 cinematic examples/aegisedge/score.wav
```

## Making it better

The strongest version of this film would read the **actual AegisEdge
repository** — the real import graph, the real signature function, the
techniques provable from its source:

```bash
python3 -m cased /path/to/AegisEdge --creative
```

That is what `--creative` is for. This hand-directed cut exists because the
repo was not available here, not because it is the better approach.
